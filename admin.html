پنل مدیریت اطلاعیه مراسم

ورود مدیر

برای انتشار پوستر، کلید دسترسی GitHub سایت را وارد کنید. این کلید فقط در مرورگر شما می‌ماند.

کلید دسترسی را از کجا بسازم؟
  1. در GitHub وارد Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens شوید.
  2. فقط مخزن همین سایت را انتخاب کنید.
  3. در Permissions، گزینه Contents را روی Read and write بگذارید.
  4. کلید ساخته‌شده را اینجا بچسبانید و آن را به کسی ندهید.

پوسترهای فعال روی سایت

۰ از ۴

این چهار جایگاه همان چیزی است که بازدیدکننده می‌بیند. پوسترها بعد از گذشتن تاریخشان خودکار برداشته می‌شوند.

۱ تاریخ مراسم

فقط امروز تا دو روز آینده قابل انتخاب است.

۲ تصویر پوستر

تصویر را بکشید و رها کنید یا انتخاب کنید. اندازه‌ی آن خودکار بهینه می‌شود.

۳ عنوان کوتاه (اختیاری)

بعد از انتشار، نمایش روی سایت حدود یک تا دو دقیقه طول می‌کشد.
